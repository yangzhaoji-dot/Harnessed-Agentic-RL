# Research Watch Update — 2026-09-18

Deduplicated against `papers/papers.csv` and repository search. Only items judged materially relevant to the current Adaptive Harness / Harnessed Agentic RL direction are included.

## 1. Rollback the World, Keep the Reflection: Rollback-Induced Reflection for Long-Horizon LLM Agents

- **arXiv:** 2609.18304 (v1 Sep 16; v2 Sep 17, 2026)
- **Why it matters:** Reframes long-horizon recovery as a joint control problem over **when to intervene, where to resume, and what information survives**. The method rolls the environment back to a prior state while carrying forward structured reflection distilled from the failed suffix.
- **Relation to our direction:** This adds a distinct Harness insertion operator beyond branch / injection / persistent activation: **rollback + retained externalized memory**. It also suggests a compact parameterization of intervention scope as `(rollback depth, retained memory)`, which maps cleanly onto our current `when + duration/scope + state carried forward` design space.
- **Boundary:** Runtime recovery; not an Agentic-RL method and not a learned Harness allocator.
- **Priority:** **Must read** for intervention-operator design.

## 2. CERA-MoA: Co-Evolving Routing Mechanisms with Continually Learning LLM Agents

- **arXiv:** 2609.18779 (Sep 16, 2026)
- **Why it matters:** The router adapts as agent capabilities change during post-training rather than assuming a fixed routing policy. A hidden-state familiarity estimator predicts competence and a cumulative-threshold rule activates a minimal agent subset, avoiding full rollout evaluation for every routing decision.
- **Relation to our direction:** This is strong evidence for the second design family we are considering: **the Harness is always present, but its configuration changes as the policy's competence changes**. The useful idea is not the learned router itself, but the use of a cheap competence signal to change active modules / budget as training progresses.
- **Novelty pressure:** CERA explicitly co-evolves a learned router and agent policies. Our current direction should therefore avoid claiming generic "routing that adapts to evolving capabilities"; the sharper space is **training-time Harness configuration without a separate learned controller**, component-level credit, and internalization/externalization boundaries.
- **Priority:** **High**.

## 3. GraphEcho: Structural Redundancy and Evidence Provenance in LLM Graph Agents

- **arXiv:** 2609.17695 (Sep 15, 2026)
- **Why it matters:** Shows that more graph paths do not necessarily mean more independent evidence. Provenance-aware post-training reduces repeated walks, but can also reduce coverage of distinct sources; on scientific claims, lower repetition does not automatically improve accuracy.
- **Relation to our direction:** Directly relevant to **research idea graphs** and **diversity-preserving RL**. An idea/evidence graph should distinguish structural multiplicity from genuinely independent provenance. A diversity objective based only on path/node novelty can reward superficial graph expansion while losing evidential coverage.
- **Design implication:** Track source/provenance identity at graph nodes/edges and separate at least two terms: **exploration diversity** and **evidence coverage/independence**. Do not treat reduced revisitation as sufficient process reward.
- **Priority:** **High** for the Creative Agent / idea-graph branch.

## Current design takeaway

The strongest update is that our Harness action space should not be limited to `trigger component` or `change configuration`. A more general intervention can be represented as:

`(component/config change, intervention time, rollback/resume point, persistence scope, retained external state)`

CERA-MoA increases novelty pressure on generic adaptive routing, while GraphEcho argues that any future research-idea graph reward must explicitly preserve **provenance diversity**, not merely structural diversity.

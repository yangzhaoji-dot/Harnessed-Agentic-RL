## 1. RRSI: Regularized Recursive Self-Improvement of Agent Harnesses
- arXiv: [2609.24972](https://arxiv.org/abs/2609.24972) — submitted 2026-09-21
- **Priority:** Must read / direct Harness-evolution collision
- **Key idea:** recursively edits a frozen model's harness while regularizing both proposal and selection. The proposer uses a temporally annealed edit budget and exploration pressure from evolution history; the selector adds a critic plus pruning for benchmark-specific, tiny, costly, or obsolete edits.
- **Reported result:** across eight coding/workspace/engineering-design benchmarks, gains reach +14.1 points on the evolve split and +4.7 points on five OOD benchmarks, while the evolved harness uses 30% fewer policy tokens than unregularized evolution.
- **Why it matters:** generic “self-evolving Harness” is now a weak novelty claim. The important unresolved problem is no longer whether Harness code can evolve, but how to attribute utility to individual components/states and how that utility should interact with policy learning.
- **Relation to our direction:** pushes us toward **state/policy-conditioned Harness configuration + component-level credit + internalization/externalization**, rather than unrestricted harness search. It also makes held-out transfer and cost regularization mandatory evaluation axes for any Adaptive Harness method.

## 2. Recursive self-improvement of AI research agents (AIDE²)
- arXiv: [2609.26457](https://arxiv.org/abs/2609.26457) — submitted 2026-09-22
- **Priority:** Must read / research-agent Harness evolution
- **Key idea:** the research agent's own code becomes the optimization target. An outer loop proposes code/harness rewrites, evaluates them under hidden criteria and a fixed per-task dollar budget, then makes accepted rewrites the starting point for the next round.
- **Reported result:** an autonomous 8-day run produced 99 proposals and seven accepted improvements, including search-policy and memory/context-management changes. The strongest evolved agent matches or exceeds a human-engineered production research agent on four held-out benchmarks; transfer to WeatherBench 2 is especially notable because that domain was absent from selection.
- **Important caveat:** the paper demonstrates net-positive recursive Harness improvement, not a proven “self-improving improver”; the authors' test of whether the evolved agent also improves the outer improvement loop was inconclusive.
- **Relation to our direction:** for Creative/Research Agents, this is strong prior for evolving the *research process itself*. Our distinct space should therefore be finer-grained: **which external research capability should be active at a given research state, how much credit it receives, and when it should remain external versus be absorbed by the policy**. Hidden/held-out evaluation also looks essential for avoiding idea/harness overfitting.

## 3. Anthropic life-sciences agent discovery: ART reverse-transcriptase system
- Official announcement: [Claude discovers a novel enzyme system with CRISPR-like repeats](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) — 2026-09-23
- **Priority:** High / scientific-ideation development rather than an RL method
- **Key development:** Anthropic reports that roughly 950 Claude agents spent about 21 hours / 210M tokens searching large genomic datasets, gathering >200K reverse transcriptases, proposing ~3,500 candidate systems, and narrowing them to 20 detailed reports. One agent noticed an anomalous repeat-array structure that became the ART candidate; human scientists performed the laboratory validation.
- **Why it matters for ideation:** the interesting part is not only the discovery claim. Anthropic explicitly describes producing hundreds-to-thousands of hypotheses/reports per campaign, then studying which ones scientists choose to test and feeding that preference back into the instructions. That is a concrete **generate-many → evidence filter → scientific-taste selection** loop.
- **Relation to our direction:** this is a strong real-world argument for separating **idea generation diversity** from **idea selection/verification quality**. For an Idea Graph / Creative Agent, Harness control can allocate search budget and operators across candidate nodes, while process-level credit can come from evidence survival and downstream validation rather than a single final novelty score. It is not yet a clean RL baseline, and ART's biological function is still unresolved, so the methodological takeaway should be separated from the biological headline.

## Method implication to retain

Two novelty boundaries became clearer this run:

\[
\text{Harness evolution itself} \;\text{is no longer sufficient as the main contribution.}
\]

A stronger Adaptive Harness formulation is:

\[
U(h_i \mid s_t, \pi_k, B)
\rightarrow
\text{activate / scale / retire external component } h_i,
\]

with separate accounting for **OOD transfer, cost, component credit, and policy-side internalization**.

For research idea generation, the operational split should be:

\[
\text{diverse candidate generation}
\;\rightarrow\;
\text{evidence-grounded selection}
\;\rightarrow\;
\text{local credit to idea / evidence nodes},
\]

rather than collapsing creativity, feasibility, and verification into one scalar reward.

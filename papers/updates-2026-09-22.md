# Research Watch — 2026-09-22

## 1. How Do Agent Harnesses Create Value? Planning Information and Release Control in Stateful LLM Agents
- arXiv: [2609.20474](https://arxiv.org/abs/2609.20474) — submitted 2026-09-17
- **Priority:** Must read / direct Harness evidence
- **Key result:** matched Fixed-vs-Sham planning controls isolate planning information; a read-only terminal verifier separately changes false acceptance and cost. Component value depends on task complexity and the loss assigned to erroneous acceptance.
- **Why it matters:** this is unusually clean evidence that Harness components should be valued separately rather than treating a full stack as one intervention.
- **Relation to our direction:** strengthens the case for measuring state/model/budget-conditional marginal utility of `Plan/Replan`, `Reflect`, and `Verify`, with cost in the utility function. It is a component-valuation study, not a learned adaptive Harness or internalization method.

## 2. Designer-RSI: Evolving Procedural Memory from User Traffic for Agentic Graphic Design
- arXiv: [2609.22086](https://arxiv.org/abs/2609.22086) — submitted 2026-09-18
- **Priority:** Must track / Creative Agent + external Harness
- **Key result:** a frozen frontier model uses an external natural-language skill memory that *widens* with new procedures and *deepens* by revising existing procedures; a matched replay gate accepts changes that repair failures without regressing prior successes.
- **Why it matters:** a concrete Creative-Agent example where the model stays fixed while the persistent external procedural layer evolves from experience.
- **Relation to our direction:** occupies adjacent prior for the route “Harness is always present but its configuration/content changes.” Our differentiator should be training-signal-driven adaptation jointly with policy learning, plus explicit externalization-vs-internalization credit rather than external-memory evolution alone.

## 3. Calibrating Teacher–Student Discrepancy for On-Policy Distillation (Cal-OPD)
- arXiv: [2609.21619](https://arxiv.org/abs/2609.21619) — submitted 2026-09-18
- **Priority:** High / internalization signal design
- **Key result:** teacher–student discrepancy contains teacher-side deviation, especially under privileged information. Cal-OPD estimates a teacher self-deviation region using positive/negative privileged interventions and trains only on discrepancy beyond it.
- **Why it matters:** privileged Harness assistance is not automatically a clean capability signal; naive distillation can internalize scaffold-specific artifacts.
- **Relation to our direction:** suggests that Harness internalization should use calibrated/counterfactual contrasts to distinguish a real policy capability gap from Harness-induced bias. This is a useful warning against equating `R_with_H - R_without_H` or teacher–student KL with pure internalizable credit.

## 4. DENSE: Distilling Agent Trajectories into Evidence-Grounded Shortcut Trees for Self-Refinement
- arXiv: [2609.21423](https://arxiv.org/abs/2609.21423) — submitted 2026-09-18
- **Priority:** High / idea-graph and process-evidence design
- **Key result:** distills execution traces into nested shortcut trees, compressing redundant attempts, reconciling issues with recovery evidence, summarizing completed branches, and leaving unresolved branches expanded; no post-hoc outcome labels are required for the feedback construction.
- **Why it matters:** provides a concrete representation for reusable local progress and unresolved obligations instead of collapsing a trajectory to one scalar outcome.
- **Relation to our direction:** useful template for idea/research graphs and localized Harness credit: attach recovery evidence and unresolved obligations to nodes/branches, then decide where extra Harness intervention is warranted.

## 5. Information-Gain Rewards over Diversity-Pruned Tests: GT-Anchored Verifier Co-Training for Reliable Code Generation
- arXiv: [2609.21208](https://arxiv.org/abs/2609.21208) — submitted 2026-09-18
- **Priority:** Adjacent but useful / diversity-preserving RL
- **Key result:** CoVer uses an information-gain reward for self-generated tests and explicitly prunes behaviorally redundant tests before reward estimation, addressing permissiveness collapse and concentration bias.
- **Why it matters:** a concrete example where diversity is enforced at *selection* time while reward measures *informativeness*, rather than rewarding superficial novelty directly.
- **Relation to our direction:** for research-idea or evidence graphs, consider separating `informativeness / discrimination` from `non-redundancy / diversity`; otherwise a single novelty scalar can reward cosmetically different but behaviorally redundant branches.

## Method implication to retain

A useful refinement of the current Adaptive Harness abstraction is:

\[
U(H_i\mid s,\pi,B)=\Delta R_i-\lambda C_i,
\]

but `\Delta R_i` should not automatically be interpreted as internalizable policy credit. For persistent/evolving Harnesses, track at least three quantities separately:

1. **component marginal utility** under the current state/policy/budget;
2. **external-memory / structural gain** that should remain outside the model;
3. **calibrated internalizable gain** after removing scaffold/teacher-side deviation.

For scientific ideation, keep **branch informativeness** and **branch diversity/non-redundancy** as distinct objectives.

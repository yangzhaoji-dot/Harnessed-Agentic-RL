# Research paper watch — 2026-09-21

No new arXiv weekend announcement batch was available on Sep 20–21. The items below are newly surfaced and not present in the current repository tracker; all are recent Sep 14–17 papers with direct relevance to Adaptive Harness / Harnessed Agentic RL.

## 1. MATCH: Model-Aware Tool Learning with Curriculum Scheduling and Hierarchically Gated Rewards

- **arXiv:** 2609.20082 — submitted 2026-09-17
- **Link:** https://arxiv.org/abs/2609.20082
- **Why it matters:** MATCH makes the training distribution track the policy's changing capability boundary. Its Model-Aware Curriculum Learning refreshes sample difficulty from reward signals, while its hierarchical tool-call reward gates credit for tool name → argument key → argument value so lower-level credit is blocked when higher-level prerequisites fail.
- **Relation to Adaptive Harness:** This is close evidence for the principle that a fixed threshold becomes stale as the policy improves. It suggests a Harness adaptation rule should be conditioned on the current capability boundary rather than a static trigger. It also gives a clean precedent for **hierarchical/gated component credit** instead of additive reward across Harness sub-decisions.
- **Novelty boundary:** “reward-derived curriculum follows the evolving policy” and “hierarchically gated tool credit” are no longer open contributions by themselves. A Harness paper should push toward component/state-specific external assistance and its internalization/externalization boundary.

## 2. Reflect, Revise, Reuse: Training-Free Skill Evolution for GUI Agents (EvoSkill-GUI)

- **arXiv:** 2609.17653 — submitted 2026-09-15
- **Link:** https://arxiv.org/abs/2609.17653
- **Code:** https://github.com/ZJU-REAL/EvoSkill-GUI
- **Why it matters:** EvoSkill-GUI treats skills as persistent editable external artifacts rather than frozen prompts. Each skill package stores retrieval metadata, executable plans, backup localization, failure-recovery rules, accessibility utilities, and failure cases. Execution feedback drives a reflect → revise → reuse loop; reported maximum gains are +16.2% on MobileWorld, +6.0% on AndroidWorld, and +10.5% on OSWorld without parameter training.
- **Relation to Adaptive Harness:** This is strong adjacent prior for the “Harness is always present but its external state/configuration changes” route. It supports separating **policy learning** from **external capability evolution**, and suggests Harness state can be a versioned, editable artifact rather than only an on/off intervention.
- **Novelty boundary:** Training-free skill evolution itself is occupied. The remaining RL question is when external skill/Harness structure should be revised, retained, weakened, or absorbed into the policy under training signals.

## 3. HypoEvolve: Genetic Algorithms Enable Multi-Agent LLMs to Discover Scientific Hypotheses

- **arXiv:** 2609.15938 — submitted 2026-09-14
- **Link:** https://arxiv.org/abs/2609.15938
- **Why it matters:** HypoEvolve keeps a population of hypotheses and makes collaboration explicit through selection, semantic variation, pairwise comparison, and replacement. The scientific roles stay fixed while the population-update rule changes, which makes the effect of collaboration/search itself testable. On 34 cancer types it reports the strongest mean external biological-support scores among six baselines; DepMap selectivity is 0.171 vs. 0.115 for the strongest baseline.
- **Relation to research idea generation / idea graphs:** This is a direct precedent for treating ideas as an evolving population with lineage rather than a single sequential draft. For an idea-graph direction, the useful abstraction is `candidate idea nodes + explicit parent/offspring lineage + independent external evidence`; diversity should be preserved at the population/replacement level rather than only by prompting different personas.
- **Relation to Adaptive Harness:** The Harness can control which operators are applied to which idea nodes and how much search budget is allocated, while keeping the scientific generator fixed. That cleanly separates Harness allocation from base-model capability.
- **Caution:** The reported gains are in drug-repurposing hypotheses with domain-specific external evaluation; they do not establish general research-idea novelty or scientific correctness.

## Takeaway for the current method

The most useful combined update is:

`current policy capability + structured local credit -> adapt external Harness configuration`

rather than a fixed threshold or globally retiring the whole Harness. For creative/scientific agents, represent ideas as an explicit population/graph and preserve lineage/diversity separately from quality or evidence reward.

## RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning

- **arXiv:** 2609.20784 (submitted Sep 17, 2026; surfaced/code update Sep 18)
- **Code:** ZJU-REAL/SDAR now includes RetireOPD.
- **Core idea:** A skill-conditioned self-teacher is first optimized with environment rewards; a skill-free student is then trained with RL + on-policy distillation. Distillation is **adaptively retired** when teacher-student discrepancy stops shrinking and the student reaches a target fraction of teacher success, after which training continues with RL alone.
- **Why it matters:** This is unusually close to the internalization/externalization question. It shows that privileged external skill supervision can be useful early but become constraining later, and that the handoff should depend on training signals rather than a fixed schedule. The student surpasses its own teacher across reported ALFWorld/WebShop settings.
- **Relation to our direction:** It directly occupies the space of **stage-dependent external assistance + internalization + adaptive retirement**. This increases novelty pressure on any proposal framed only as “use Harness early, then withdraw it as the model learns.” Our sharper remaining space is **heterogeneous Harness components**, state/component-level credit, dynamic configuration during trajectories/training, and learning which capabilities should remain external rather than globally retiring one teacher.
- **Useful design lesson:** Privileged context alone does not guarantee a useful Harness/teacher; the teacher itself must be competent. For our setting, component utility should be measured before treating a component as beneficial supervision.
- **Priority:** **Must read / direct collision**.

## Current design takeaway

A stronger formulation of the current research question is no longer just “when should external assistance be removed?” but:

`which Harness capability should be active / weakened / retired, at which state and training stage, based on what credit signal, and which capabilities should remain external?`

RetireOPD covers a global teacher-retirement instance of this problem; it does not solve component-level or state-dependent Harness allocation.

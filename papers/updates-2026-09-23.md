## 1. MemCalib: Benchmarking and Optimizing Memory Use in LLM Agents
- arXiv: [2609.24259](https://arxiv.org/abs/2609.24259) — submitted 2026-09-21
- **Priority:** Must read / counterfactual Harness-use credit
- **Key result:** models systematically over-use or under-use external memory. MemCalib-RL separates these directions into ordered reward channels, then uses exact atom ablation to localize response-level credit to tokens. Across Qwen3-8B, Ministral-3-8B-Instruct, and Qwen3.5-35B-A3B it is reported as the only tested method that improves both directions consistently.
- **Why it matters:** this is a concrete demonstration that an external component can be harmful both when it is ignored and when it is over-relied on; a single scalar `with-Harness > without-Harness` signal misses this asymmetry.
- **Relation to our direction:** for Adaptive Harness, component utility should include *degree of influence*, not only activation. Counterfactual atom/component ablation is also a strong template for localizing credit to the policy tokens that actually consume Harness output.

## 2. CREDO: Variance-Guided Rubric Evolution for Replay-Corrected Credit Assignment
- arXiv: [2609.24174](https://arxiv.org/abs/2609.24174) — submitted 2026-09-21
- **Priority:** High / branch-credit theory; preliminary
- **Key idea:** combines evolving semantic process rubrics with selectively sampled two-sided continuation replays. Replay residuals correct a learned credit head, while a variance decomposition jointly determines which rubric features to retain and where to spend a fixed replay budget; the allocation also accounts for continuation cost.
- **Why it matters:** it gives a principled answer to a problem close to our branch/intervention line: exhaustive counterfactual suffix rollout is too expensive, so replay should be allocated where credit uncertainty and policy sensitivity justify the cost.
- **Relation to our direction:** suggests replacing heuristic Harness probing with a budgeted criterion over `(state, component)` interventions, and using replay evidence to revise the process rubric/credit model itself. Important caveat: the report is theoretical/preliminary and explicitly does **not** claim empirical superiority on language-agent benchmarks yet.

## 3. MiMo-V2.6-Pro-RL / MiMo-V2.6 agentic-RL release
- Official release: [Xiaomi MiMo-V2.6](https://mimo.xiaomi.com/mimo-v2-6/article) — released 2026-09-22
- Model/report: [XiaomiMiMo/MiMo-V2.6-Pro-RL](https://huggingface.co/XiaomiMiMo/MiMo-V2.6-Pro-RL)
- **Priority:** High / multi-Harness Agentic RL development
- **Key development:** Xiaomi reports one mixed RL run spanning coding, general-agent, visual, and cybersecurity tasks, with tasks from multiple harnesses mixed in the same batches. The run uses large-scale asynchronous GRPO plus Groupwise Reward Synthesis (offline task-specific rubrics from contrasting rollouts) and Groupwise Advantage Redistribution (online ranking/advantage redistribution among passing trajectories). Xiaomi also released the training environments and RL code.
- **Why it matters:** this is concrete evidence that policy learning can be trained *across heterogeneous harnesses* instead of binding one policy to one fixed runtime scaffold, while richer groupwise grading provides process-sensitive signal beyond binary success.
- **Relation to our direction:** raises the bar for a generic claim such as “train one model under multiple harnesses.” Our stronger target remains **adaptive allocation/configuration of Harness components conditioned on state and current capability**, plus explicit externalization/internalization credit. The released environments/code may also be useful infrastructure evidence even though the flagship model scale is far above our intended 1.5B–7B experiments.

## Method implication to retain

Two refinements look increasingly important:

\[
\text{Harness control} \neq \text{binary on/off};\qquad
H_t \text{ should include influence/strength as well as activation.}
\]

and, for expensive counterfactual probing,

\[
\text{probe priority}(s,h)
\propto
\frac{\text{credit uncertainty} \times \text{policy sensitivity}}{\text{continuation cost}}.
\]

This points toward a compact Adaptive Harness formulation: learn or estimate the marginal utility and required strength of each external component, while spending counterfactual rollout budget only where the expected credit information is high.

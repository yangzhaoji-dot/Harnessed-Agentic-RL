# Research Update — 2026-09-09

High-signal papers affecting scientific ideation, idea graphs, process-level reward / credit assignment, diversity-preserving RL, and Harness × Agentic RL.

## Must read

### AgentIdeaBench: Benchmarking Scientific Ideation in the Agent Era
- arXiv: https://arxiv.org/abs/2609.07611
- Submitted: 2026-09-07
- Why it matters: directly benchmarks scientific ideation under **static observation vs active exploration** across 33 LLMs / 40 subfields / five disciplines.
- Key result: active exploration improves grounding, feasibility, clarity and specificity, but **measured originality does not improve**.
- Implication: retrieval/exploration alone is not a solution to creative collapse; scientific ideation needs an explicit novelty / epistemic-diversity mechanism.

### Procedural Graphs: Self-Evolving Execution Structures for LLM Agents
- arXiv: https://arxiv.org/abs/2609.09153
- Submitted: 2026-09-08
- Core idea: procedural knowledge is represented as a graph of `(procedure, relation, procedure)` triplets. The active node is localized at each step and the surrounding subgraph supplies situational guidance.
- Evolution: failed and successful trajectories are contrasted to edit topology and node attributes; edits are committed only if held-out validation is preserved/improved.
- Implication for idea graphs: an idea graph can be an **executable and self-evolving control structure**, not merely memory or visualization.

### AutoKD: Autonomous Knowledge Discovery
- arXiv: https://arxiv.org/abs/2609.06366
- Submitted: 2026-09-06
- Core idea: six-agent open-ended discovery loop with a **persistent insight graph**; validated findings accumulate and steer later exploration.
- Implication: `persistent graph for cumulative scientific discovery` is now direct prior art. Novelty for future work needs to go beyond persistence itself toward graph credit, learned edit policies, diversity, RL, or causal validation.

### Difficulty-Adaptive Tree-Structured Policy Optimization for Expanding Reasoning Coverage in RLVR (DATPO)
- arXiv: https://arxiv.org/abs/2609.08650
- Submitted: 2026-09-08
- Core finding: RLVR can improve pass@1 without expanding intrinsic reasoning coverage / pass@k.
- Method: difficulty-adaptive tree rollout + **sentence-entropy-guided forking** + sibling-diversity advantage.
- Key insight: sentence-level branching improves semantic diversity over token-level branching.
- Implication for research-idea RL: preserve **semantic branch coverage**, not merely token entropy; tree structure and sibling diversity are concrete algorithmic primitives for diversity-preserving idea generation.

### Co-Evolving Harnesses and Models: On-Policy Correction Helps Weaker Models Catch Up Where Imitation Fails
- arXiv: https://arxiv.org/abs/2609.09134
- Submitted: 2026-09-08
- Key result: after a harness is evolved around a weaker model, imitating a stronger model's complete trajectories can **hurt by 4–30 points** across seven tasks because it breaks model–harness fit.
- Method: localize the failing turn in the weaker model's **own on-policy rollout**, then ask the expert to rewrite only that turn.
- Implication: better trajectories are not automatically better supervision; local on-policy correction can preserve policy/harness compatibility. Strong evidence for process-level intervention instead of whole-trajectory imitation.

### Experience Funnel: A State-Policy Alternating Loop for Self-Evolving Agents
- arXiv: https://arxiv.org/abs/2609.08919
- Submitted: 2026-09-08
- Core idea: alternate fast explicit textual-state adaptation (skills / harnesses) with slow model-policy consolidation; selectively internalize state-enabled behavior that remains useful across state revisions.
- Implication: direct new prior for **Harness capability handoff/internalization**. Generic `external state evolves -> useful capability distilled into weights` is becoming crowded; stronger novelty needs causal attribution, heterogeneous component handoff, or principled retirement criteria.

## Credit assignment / process supervision

### MeClear: Cooperative Game-Theoretic Attribution and Risk-Aware Memory Clearance for Long-Horizon LLM Agents
- arXiv: https://arxiv.org/abs/2609.09115
- Submitted: 2026-09-08
- Method: Leave-One-Out screening + sampled cooperative Shapley attribution to distribute downstream utility among **interacting evidence items**.
- Why it matters: single-node removal can fail under redundancy/conflict masking. Idea/evidence graph credit may need **coalitional attribution**, not independent node scores.

### AgentGrad: Intervention-guided Prompt Optimization for Multi Agent Systems
- arXiv: https://arxiv.org/abs/2609.08572
- Submitted: 2026-09-08
- Core idea: intervene on one agent at a time and only assign/update credit when the intervention actually fixes the failure; cluster related gradients before abstraction.
- Implication: `intervention before update` is a strong design principle for node/component credit.

### SRPO: Setwise Relative Policy Optimization for Multi-Agent LLMs
- arXiv: https://arxiv.org/abs/2609.08452
- Submitted: 2026-09-08
- Core idea: when multiple outputs jointly cause one environment transition, treat the **minimal consumed set** as one multi-agent action and assign one relative advantage to that set.
- Implication: the credit/update unit should match the actual causal action unit. Relevant to proposer–critic–evidence agent groups jointly committing one idea-graph transition.

## Feedback / scaffolding

### Environments as Scaffold: Enriching Feedback to Bootstrap Self-Evolving Agents in Long-Horizon Tasks
- arXiv: https://arxiv.org/abs/2609.08404
- Submitted: 2026-09-08
- Core idea: adapt the environment into Feedback-Enriched Environments rather than relying only on agent-side SFT warming.
- Results: across SciWorld/BFCL and GRPO/GSPO/DAPO, feedback enrichment stabilizes entropy, improves hard-task exploration, and appears to be internalized into policy weights.
- Important boundary: **intra-group feedback consistency** is identified as critical for stable optimization.

## Diversity / discovery search

### GoAnt: Quality-Diversity Multi-Agent Search for Alpha Factor Discovery in Market Microstructure Data
- arXiv: https://arxiv.org/abs/2609.08719
- Submitted: 2026-09-08
- Core idea: quality-diversity search with Explorer / Exploiter / Connector workers and a shared adaptive Mental Map; keep one elite per behavioral niche and dynamically reallocate evaluation budget.
- Implication for ideation: a promising alternative to entropy regularization is **niche-based diversity preservation** (MAP-Elites style): define idea niches and preserve the best nonredundant idea in each niche.

## Current synthesis

The strongest new pattern is:

`Persistent / Executable Idea Graph`
`+ Semantic Coverage (tree / niche diversity)`
`+ Intervention- or coalition-aware credit`
`+ Local on-policy correction`
`+ Evidence that useful external state can be consolidated into policy`

Two novelty warnings for our direction:
1. A **persistent scientific insight graph by itself is no longer novel** (AutoKD).
2. **Harness/state evolution followed by model internalization by itself is also increasingly direct prior art** (Experience Funnel and related work).

A stronger research contribution likely needs to combine persistent graph structure with principled causal/process credit and an explicit mechanism that preserves rare but valid scientific branches during RL.
